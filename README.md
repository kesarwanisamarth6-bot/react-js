# ReactJS Learning Projects

This repository contains a collection of beginner-friendly React projects created to practice core frontend development concepts. Each folder focuses on a different concept, helping build a strong foundation in React and component-based UI design.

## Overview

The projects in this workspace cover topics such as:

- Basic React setup and Vite configuration
- Components and reusable UI blocks
- Props and data passing
- Card-based layouts and UI composition
- Project structure and component organization
